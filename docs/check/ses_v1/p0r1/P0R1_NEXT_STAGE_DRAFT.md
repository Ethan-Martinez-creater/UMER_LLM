# SES-v1 P1 设计草案（R1 修订版，一页，供研究评审；未授权执行）

R1 修订（F2/F3）：修正发现/确认集污染；annotation、最终 V、人工审查结果与历史修复后材料全部从可部署输入剥离；`distinct_falsifiable_hypothesis` 已降为 UNRESOLVED——本草案不预注册实验，仅描述若获批的形态。

## 1. 样本与隔离（F2 修复）

- 固定 60 条（原盐 manifest 不变）与 R1 增查 12 条全部属于**发现集**；凡正文、纠错或结果影响过设计的线程，连同其**同主张/同上游复制来源线程**，永久不得进入最终确认评测。
- 剩余池分母 = **2402 − 60 = 2342** 个未审读线程（此前 2184 系笔误）。确认集只能从 2342 中构造，且必须按"同主张/复制来源归组"先做隔离聚类（基于 thread 间共享 URL/同文引述/同事件同主张），**整组退出**后才能抽样；本轮不读其正文、不冻结任何"已被设计调过的假确认集"。
- 统计层级明确三分：thread / claim（同主张跨线程）/ topic，不得混称 event。

## 2. 可部署输入边界（F3 修复）

- reader 可见输入仅限：截点前源帖与回复文本、回复树结构、时间戳、推文自带实体链接。
- **不可进入部署输入**：annotation 的 for/against/observing 链接（仅离线核查定位）、最终 V、人工审查意见、晚于截点的存档内容。
- 回复间的确认/附和**不产生独立来源权重**；子回复对其父回复的依赖须在计数时折叠。

## 3. 机制现状（诚实结论）

- H1 的 URL/RT 分组计数与其最强规则去重基线未显示实质算法差异；H2 "只改选择与权重"不足证明创新；WFW §6 已含同源重复合并缓解。`distinct_falsifiable_hypothesis=UNRESOLVED`。
- 若 P1 获批，先做的是**双人标注可标注性研究**（发现集内 60 条，人员 `PENDING_HUMAN_RESOURCE`）：验证依赖/纠错观察能否被独立标注者稳定复现（κ≥0.7），而不是先设计方法。
- 冻结 reader 实验臂（仅在设计获批后另行审批）：规则 URL/RT 去重（最强基线）、精确/语义去重、来源检查提示、匹配覆盖率拒判，与任何候选机制同 token/同覆盖率比较；新任务为 veracity/证据安全，**不能沿用 A=RUMOR/B=NON_RUMOR 旧 contract**，新标签/拒判动作/校准/prompt 须另审批。
- 主指标以判决层错误风险、同覆盖率比较、有效纠错响应与反向误更新为基础；"被选中的某些行比例"只作诊断。true→wrong / false→correct 指 reader 预测转移，不是数据标签转移。
